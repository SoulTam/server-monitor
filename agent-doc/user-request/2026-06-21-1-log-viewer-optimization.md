# 日志浏览优化需求

## 结构化请求（经提示词增强确认）

**需求描述**：
1. 日志浏览Modal左侧文件列表改为仅显示文件名（从全路径中提取 basename），并按文件名倒序（Z→A）排列。
2. 左侧文件列表与右侧内容显示区域之间增加可拖动的分割条（split pane），支持鼠标拖动调整宽度。
3. 日志文件读取改为分片滚动加载：首次加载文件前N字节/行，用户滚动到底部时自动加载后续内容，类似 `more` 命令的行为。
4. SSH_COMMAND_TIMEOUT当前为5000ms（5秒），当通过`cat`全量读取大日志文件时容易超时。请确认原因并修复。

**约束条件**：
- 技术：Electron + React + TypeScript + Ant Design 5
- 质量：保持与现有代码风格一致，不使用额外第三方库（除非必要）
- 安全：维持现有的路径安全检查（filePath.startsWith(logsPath)）

**期望输出**：代码修改 + SSH超时问题根因分析与修复方案
