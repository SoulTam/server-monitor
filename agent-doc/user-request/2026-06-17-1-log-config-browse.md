## 请求内容
添加一个功能，用户可以为服务器配置日志文件路径，配置后，用户可以浏览服务器上的日志。应用根据路径文件夹，显示可以阅读的文件。日志文件内容如果是JSON格式，则优化JSON后显示，如果是纯字符串则直接按照日志文件原始格式显示内容。当用户配置了日志文件目录路径后，显示"浏览日志"按钮，如果没有配置，则显示"配置日志"按钮。点击"配置日志"按钮后，用户在提示框内填写日志目录路径完成配置。
