# 功能设计文档：日志浏览优化

## 1. 功能一：文件名显示 + 倒序排列

**用户操作**：打开日志浏览Modal
**系统行为**：
1. 调用 `log:list` 获取文件全路径列表
2. 对每个路径提取 basename（取最后一个 `/` 之后的部分）
3. 按 basename 做 localeCompare 倒序排列（Z→A）
4. 列表项仅显示 basename，不显示目录前缀
5. 选中某个文件时传入 fullPath 去读取内容

**验收标准**：
- 文件列表显示 `app.log` 而非 `/var/log/myapp/app.log`
- 列表按文件名倒序排列（z > y > x > ... > a）

## 2. 功能二：拖拽分割面板

**用户操作**：鼠标悬停在左右面板交界处 → 光标变为 col-resize → 按下并拖拽
**系统行为**：
1. 鼠标按下分割条时，标记拖拽开始
2. 鼠标移动时，计算新的左侧面板宽度（最小200px，右侧最小300px）
3. 鼠标松开时，标记拖拽结束
4. 拖拽过程中左侧和右侧面板实时调整宽度

**验收标准**：
- 分割条悬停时显示拖拽光标
- 拖拽流畅无卡顿
- 左侧面板宽度≥200px，右侧面板宽度≥300px

## 3. 功能三：分片滚动加载

**用户操作**：点击文件列表中某个文件 → 首次加载前64KB内容 → 滚动到内容区域底部 → 自动加载下一片段
**系统行为**：
1. 用户点击文件：清空内容区，offset=0，调用 `log:read` 传递 offset=0, length=65536
2. 首次响应：显示已加载的文本内容
3. 用户滚动到底部（距底部<100px）：自动调用 `log:read` 传递 offset=previous_offset+chunk_bytes, length=65536
4. 当返回的内容长度 < 65536 时：标记 hasMore=false，不再继续加载
5. 加载过程中显示"加载中..."提示

**验收标准**：
- 首次加载只读取前64KB，不读全文件
- 滚动到底部自动触发下一片段加载
- 大文件不出现 SSH_COMMAND_TIMEOUT

## 4. SSH超时修复

**问题**：SSH_COMMAND_TIMEOUT=5000ms，`cat` 全量读取大文件时超时
**修复**：
1. SSH_COMMAND_TIMEOUT 从 5000 改为 30000
2. 前端始终使用分片读取（传递 offset/length），不走全量 cat 路径

**验收标准**：
- 读取100MB文件不再出现 SSH_COMMAND_TIMEOUT 错误
